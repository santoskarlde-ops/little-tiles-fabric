# Round 84 — Sodium/Iris fallbacks, camera/frustum/dispatcher lookups (uncompiled)

Apply after Round 83. Paste this entry at the top of PORT_NOTES.md.

- `client/compat/sodium/SodiumManager` and `client/compat/iris/IrisManager` (new): Fabric compile-time fallbacks, same pattern as `common/compat/sable/SableManager`. They carry only the API the compiled code calls (`installed()`, `init()`, `RENDERING_LEVEL`, `RENDERING_ANIMATION`, `createRenderManager`, `isShaders()`, `beginBlock`, `resetBlockContext`). Sodium and Iris are reported as not installed, so every caller takes the vanilla path. The real integrations stay in the excluded `client/mod/*` folders; when they are ported, these two classes are replaced and the imports pointed back. Five files import them instead of `client.mod.*`: `LittleTilesClient`, `LittleAnimationHandlerClient`, `RenderingLevelHandler`, `LittleAnimationRenderManager`, `LittleRenderPipelineForge`. Targets 6 package errors and 11 usage errors from the Round 82 log. Users running Sodium on Fabric get no Sodium-specific LittleTiles rendering until that port.
- `BufferHolder`: no longer imports Sodium's `ModelQuadFacing`; it compares against a constant `UNASSIGNED_FACING = 6` (six directions precede `UNASSIGNED` in Sodium's enum). The value 6 is from memory of Sodium's source, not checked against the jar. Targets 2 errors.
- `LittleRenderPipelineForge`: `Minecraft.useAmbientOcclusion()` is now `Minecraft.getInstance().options.ambientOcclusion().get()` (`Options.ambientOcclusion()` is in the 26.3 dump).
- `RenderChunkExtender`: `levelRenderer.getSectionRenderDispatcher().getCameraPosition()` is now `gameRenderer.mainCamera().position()`. `SectionRenderDispatcher` has `setCameraPosition` but no getter in 26.3 and `LevelRenderer.sectionRenderDispatcher()` is the new name; the camera position is the one the dispatcher is given.
- `LittleLevelRenderManager`, `LittleRenderChunk`: the two remaining `origin.pose(partial)` calls (gone from CreativeCore's `IVecOrigin`) now use `VecOriginPose.of(origin, partial)`, as every other call site already does. `LittleLevelRenderManager` also lost `Camera.getPartialTickTime()`; it now uses `getDeltaTracker().getGameTimeDeltaPartialTick(false)` like the rest of the tree.
- `PreviewRenderer.isVisible`: `LevelRenderer.getFrustum()` is now `gameRenderer.mainCamera().getCullFrustum()` (in the Camera dump).
- Source-reviewed only; every changed file parsed with the JDK compiler. Expected: about 25 locations removed (17 Sodium/Iris, 2 `ModelQuadFacing`, 1 ambient occlusion, 1 dispatcher, 2 `pose`, 1 partial tick, 1 frustum). No new count is claimed.
